### Scene2_Concepts — Defining Eigen-Equation

### Scene3_VisualIntuition — Transformation Animation

- Builds a `NumberPlane` with the matrix label in the corner.

### Scene4_WorkedExample — Algebraic Derivation

- **Step 1**: Shows the eigen-equation Av = λv → (A − λI)v = 0 → det(A − λI) = 0.
- **Step 2**: Writes out A − λI as a matrix, computes the determinant (3−λ)(2−λ) = 0, boxes the result λ₁ = 3, λ₂ = 2.
- **Step 3**: For λ₁ = 3, writes (A − 3I) = [[0,1],[0,−1]], solves to get y = 0, x free → v₁ = [1,0].
- **Step 4**: For λ₂ = 2, writes (A − 2I) = [[1,1],[0,0]], solves x + y = 0 → v₂ = [−1,1].
- Each step fades in sequentially with boxed results.

## generate_tts.py — Voice-Cloned Narration Generation

- Uses the local zero-shot **F5-TTS** (`F5TTS_v1_Base`) diffusion flow-matching TTS model running on Apple Silicon (`MPS`) with the student's pre-processed voice recording (`voice_ref.wav`, derived from `voice_sample.m4a` via FFmpeg `-ar 22050 -ac 1`, `afftdn` noise reduction, and `loudnorm`).
- Uses a clean 8.8-second speech segment with its exact transcript as the zero-shot speaker prompt so the synthesized voice matches the student's timbre and cadence.
- Generates scene-by-scene narration for Scenes 1–6 from `_Code/narration_script.txt`, tightens inter-sentence pauses and applies gentle FFmpeg `atempo` / `apad` timing synchronization to match each rendered Manim scene's exact duration, and normalizes loudness (`loudnorm=I=-16:TP=-1.5:LRA=11`) at 48 kHz stereo.
- Measures and writes durations to `durations.json` (and retains an `edge-tts` fallback mode).

## verify_eigen.py — Mathematical Verification

- Defines A, v₁, v₂, λ₁, λ₂ as NumPy arrays.
- Checks A @ v₁ == λ₁ * v₁ and A @ v₂ == λ₂ * v₂ using `np.allclose`.
- Cross-checks with `np.linalg.eig(A)` to confirm eigenvalues are {2, 3}.
- All assertions must pass before rendering proceeds.

## render_and_merge.sh — Build Pipeline

1. Activates the Python virtual environment.
2. Runs `verify_eigen.py` — aborts if the maths doesn't check out.
3. Runs `generate_tts.py` to create all audio files and durations.
4. Renders each of the 7 Manim scenes with `manim render -qh --fps 30`.
5. For scenes 1–6, merges each rendered video with its corresponding MP3 audio using FFmpeg.
6. For scene 0 (no narration), adds a silent audio track.
7. Concatenates all 7 clips into the final `_Video.mp4` using FFmpeg's concat demuxer.
8. Runs `ffprobe` to verify 1920×1080, H.264 + AAC, and duration < 7:00.
